# Technology Stack

## Backend
- **Language**: Go (Golang)
- **Framework**: Standard Library (`net/http`) for minimal dependencies and high performance.
- **Testing**: Standard Go `testing` package.

## Frontend
- **Language**: Vanilla JavaScript (ESM)
- **Mapping Library**: Leaflet.js for map rendering and interactions.
- **Styling**: CSS3 with a focus on simplicity and responsiveness.
- **Testing**: Jest for unit and integration testing of frontend logic.

## Infrastructure & Tooling
- **Local Storage**: Filesystem-based storage for GPX files and map tile cache.
- **Version Control**: Git
