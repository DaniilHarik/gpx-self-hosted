# Initial Concept

A lightweight, self-hosted web application for browsing, visualizing, and drawing GPX tracks locally. It scans a local directory for `.gpx` files and displays them on an interactive map.

## Target Users
- **Individual outdoor enthusiasts**: Hikers, cyclists, and runners who want to organize and review their activities locally.
- **Data hoarders**: Users who prioritize local storage and control over their data over cloud-based services.

## Core Goals
- **Data Privacy and Ownership**: Ensure all data stays on the user's hardware, providing full control and security.
- **Maintainability and Extensibility**: Maintain a modular structure that is easy for both developers and AI agents to understand and extend.

## Key Features
- **Automatic Indexing**: Seamlessly scan local directories for GPX files and display them in the UI.
- **Interactive Visualization**: Provide a map-centric interface for viewing tracks with multiple layer options (OSM, Topo, etc.).
- **Track Creation**: Enable users to draw new routes directly on the map and export them for use in other devices.

## User Experience
- **Lightweight and Fast**: A minimalistic design that focuses on performance and core utility.
- **Familiar and Intuitive**: Leverage standard mapping conventions to ensure the application is easy to use from the start.
